# 07 – Bug Reports

Folder ini berisi laporan defect/bug yang ditemukan selama pengujian.

## Template Bug Report

| Field | Keterangan |
|---|---|
| Bug ID | BUG-001 |
| Judul | Ringkasan masalah |
| Lingkungan | Browser/perangkat/versi aplikasi |
| Prasyarat | Kondisi sebelum bug terjadi |
| Langkah Reproduksi | Langkah untuk memunculkan bug |
| Hasil Aktual | Perilaku yang ditemukan |
| Hasil yang Diharapkan | Perilaku seharusnya |
| Severity | Tingkat dampak |
| Priority | Urutan penanganan |
| Bukti | Tautan screenshot/video |
| Status | Open / In Progress / Fixed / Retest / Closed |

Gunakan severity dan priority secara konsisten. Sertakan langkah reproduksi yang jelas dan bukti yang relevan.
