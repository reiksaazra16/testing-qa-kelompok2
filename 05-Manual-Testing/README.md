# 05 – Manual Testing

Folder ini menyimpan dokumentasi pengujian manual, termasuk teknik Black Box dan White Box jika akses kode tersedia.

## Isi
- Pengujian fungsional Black Box.
- Pengujian White Box sesuai akses dan ruang lingkup.
- Hasil aktual dibandingkan dengan hasil yang diharapkan.
- Screenshot atau bukti pengujian.

## Format hasil
Catat ID test case, tanggal, penguji, langkah, hasil aktual, status (Pass/Fail/Blocked), dan tautan bukti. Jangan menyatakan pengujian berhasil tanpa bukti pelaksanaan.
