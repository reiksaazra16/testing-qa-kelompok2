# 06 – Automation Testing

Folder ini berisi kode, konfigurasi, dan hasil pengujian otomatis.

## Struktur yang disarankan
- `scripts/` – script automation.
- `config/` – konfigurasi lingkungan uji tanpa kredensial rahasia.
- `test-results/` – ringkasan hasil eksekusi.
- `README.md` – cara instalasi dan menjalankan pengujian.

## Dokumentasi
Tuliskan tools dan versinya, prasyarat, cara menjalankan script, cakupan test, serta ringkasan hasil. Simpan password, token, dan secret di environment variable; jangan commit ke repository.
