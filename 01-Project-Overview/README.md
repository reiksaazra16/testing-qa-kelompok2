# 01 – Project Overview

Folder ini berisi gambaran umum proyek dan aplikasi yang akan diuji.

## Dokumen yang disiapkan
- `latar-belakang.md` – latar belakang pemilihan objek pengujian.
- `profil-aplikasi.md` – nama, fungsi, pengguna, dan fitur aplikasi.
- `tujuan-pengujian.md` – tujuan dan manfaat pengujian.
- `ruang-lingkup.md` – fitur yang termasuk dan tidak termasuk dalam pengujian.

## Informasi Objek
Lengkapi identitas aplikasi, versi, platform, URL (jika tersedia), serta lingkungan pengujian. Pastikan informasi sesuai kondisi sebenarnya.
