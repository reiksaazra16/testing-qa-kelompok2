# 04 – Test Cases

Folder ini berisi skenario, kasus uji, dan data yang diperlukan untuk menjalankan pengujian.

## Dokumen
- `test-scenarios.md` – daftar skenario berdasarkan fitur.
- `test-cases.md` – langkah pengujian dan hasil yang diharapkan.
- `test-data.md` – data valid, tidak valid, dan data batas (boundary).

## Template Test Case

| ID | Fitur | Prasyarat | Langkah Pengujian | Data Uji | Hasil yang Diharapkan | Status |
|---|---|---|---|---|---|---|
| TC-001 | Isi nama fitur | Isi prasyarat | Tulis langkah | Isi data | Tulis hasil yang diharapkan | Belum diuji |

Gunakan ID unik dan pastikan setiap hasil aktual dicatat setelah pengujian dilakukan.
