# 09 – Final Report

Folder ini berisi laporan akhir kegiatan Testing dan QA.

1. Pendahuluan dan profil aplikasi.
2. Landasan teori dan standar referensi.
3. Perencanaan dan strategi pengujian.
4. Skenario, test case, dan data uji.
5. Pelaksanaan pengujian manual/otomatis.
6. Hasil pengujian dan analisis bug.
7. Kesimpulan dan saran.
8. Daftar pustaka.
9. Lampiran bukti pengujian dan dokumentasi.

Pastikan angka, status pengujian, dan kesimpulan konsisten dengan bukti pada folder sebelumnya.
