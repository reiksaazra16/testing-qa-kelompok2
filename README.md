# Testing QA – Kelompok Mata Kuliah

Repositori ini digunakan sebagai pusat dokumentasi dan penyimpanan seluruh aktivitas proyek **Software Testing dan Quality Assurance (QA)** kelompok.

## Struktur Repository

| Folder | Isi |
|---|---|
| [01-Project-Overview](01-Project-Overview/) | Latar belakang, profil aplikasi, tujuan, dan ruang lingkup |
| [02-Standards-References](02-Standards-References/) | ISO, IEEE, jurnal SINTA, dan landasan teori |
| [03-QA-Planning](03-QA-Planning/) | Test Plan, strategi, jadwal, dan pembagian tugas |
| [04-Test-Cases](04-Test-Cases/) | Test scenario, test case, dan test data |
| [05-Manual-Testing](05-Manual-Testing/) | Black Box, White Box, dan bukti pengujian |
| [06-Automation-Testing](06-Automation-Testing/) | Script automation dan hasil eksekusi |
| [07-Bug-Reports](07-Bug-Reports/) | Daftar bug, severity, priority, dan screenshot |
| [08-Interview](08-Interview/) | Profil narasumber, pertanyaan, transkrip, dan dokumentasi |
| [09-Final-Report](09-Final-Report/) | Laporan akhir dan kesimpulan |

## Cara Berkontribusi

1. Buka folder sesuai bagian pekerjaan.
2. Tambahkan dokumen dengan nama file yang jelas dan konsisten.
3. Sertakan bukti pendukung seperti screenshot atau hasil eksekusi jika diperlukan.
4. Gunakan commit message yang menjelaskan perubahan.
5. Hindari mengunggah data pribadi, kredensial, atau informasi rahasia.

## Catatan

Sesuaikan isi dokumen dengan aplikasi yang menjadi objek pengujian dan hasil pengujian yang benar-benar dilakukan. Jangan mengisi hasil pengujian atau temuan bug berdasarkan asumsi.
