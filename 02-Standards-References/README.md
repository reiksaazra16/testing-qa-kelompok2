# 02 – Standards & References

Folder ini menyimpan standar, referensi ilmiah, dan teori yang menjadi dasar kegiatan QA.

## Materi
- ISO/IEC 25010 – model kualitas produk perangkat lunak.
- ISO/IEC/IEEE 29119 – standar software testing.
- Standar atau panduan IEEE yang relevan.
- Jurnal ilmiah, diutamakan jurnal terakreditasi SINTA sesuai ketentuan tugas.
- Landasan teori terkait software testing dan quality assurance.

## Format pencatatan referensi
Catat judul, penulis, tahun, penerbit/jurnal, DOI atau URL, serta tanggal akses bila diperlukan. Pastikan sumber dapat diverifikasi dan kutipan ditulis secara konsisten.
