# 03 – QA Planning

Folder ini berisi perencanaan kegiatan pengujian.

## Dokumen
- `test-plan.md` – tujuan, ruang lingkup, pendekatan, lingkungan, kriteria masuk/keluar, dan risiko.
- `test-strategy.md` – jenis dan teknik pengujian yang digunakan.
- `jadwal-pengujian.md` – tahapan dan target waktu.
- `pembagian-tugas.md` – penanggung jawab setiap aktivitas.

## Panduan
Tentukan fitur prioritas, kebutuhan perangkat dan akun uji, data pengujian, serta kriteria keberhasilan sebelum eksekusi.
